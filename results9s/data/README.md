# Packaged Inputs

These are analysis-ready inputs copied from the original project outputs so the final figures can be regenerated without the full raw fMRI dataset.

- `ablation/objective_evaluation/`: Fold-level and model-summary CSVs for the objective ablation figure.
- `ablation/maps/`: Thresholded NIfTI maps for the single-network and two-network overlay figures.
- `anatomy/`: MNI anatomy used as the brain-map background.
- `behavior_vs_bold/`: Run-level behavior/projection metrics for the behavior-vs-BOLD panel.
- `connectivity/roi_edge_network/`: Pairwise network metrics and top-edge delta heatmap data.
- `connectivity/gvs/without_unassigned/`: Subject/session ROI significance tables for GVS burden heatmaps.
- `hypothesis/`: Trial-variability hypothesis arrays and state-selection follow-up tables.
